# 🔗 链接有效性检查器

批量检查 + 定时监控链接可用性的本地网页工具。零依赖，仅需 Python 3。

## 使用

```bash
cd /Users/chenmin/Documents/ChatGPT/connection_check
python3 server.py          # 默认 http://localhost:8000
python3 server.py 9000     # 自定义端口
```

浏览器打开 **http://localhost:8000**。

## 功能

### 📋 批量检查

- 导入：直接粘贴（自动识别文本中的 http/https 链接）、上传文件（.txt / .csv / .html，含浏览器书签导出）、拖拽文件，自动去重
  - 支持两列格式：每行「名称 + Tab + 链接」，名称会展示在结果表格、监控网格和 CSV 导出中；也支持浏览器书签导出的 `名称\t链接` 格式
- 检查：并发（默认 15 条同时），跟随重定向，结果实时流式显示，可随时停止
- 结果：名称、状态码、最终链接（重定向后）、响应耗时、中文错误原因；按 有效 / 无效 / 无法访问 筛选
- 导出：CSV（Excel 可直接打开）
- 判定：2xx / 3xx 为有效；4xx / 5xx 为无效；DNS 失败、超时、SSL 错误等为无法访问

### 📈 定时监控

- 按设定间隔（分钟，可小数，最小 0.1）自动检查输入框中的链接
- 结果持久化到 SQLite（`monitor.db`，保留 30 天），服务重启后自动恢复监控
- 可视化：
  - 每轮可用率趋势折线图
  - 链接 × 轮次状态网格（绿 = 有效，红 = 无效，橙 = 无法访问）
  - 点击任一链接查看详情：可用率、平均响应时间、失败次数、响应时间曲线
- 可随时「立即检查一轮」，页面每 10 秒自动刷新

### 👤 登录与多用户（可选）

- 不登录（游客模式）即可使用全部功能，游客数据为共享的公共数据（升级前的历史数据自动归为游客数据）
- 右上角「登录 / 注册」：注册后链接与监控数据（配置 + 历史）仅自己可见，不同用户互不影响
- 登录用户输入框内容自动保存到服务端，重新登录后自动恢复；游客的输入内容保存在浏览器本地
- 登录状态下退出登录不影响监控：监控在服务端后台继续运行，服务重启后所有用户的监控都会自动恢复
- 会话令牌保存在浏览器 localStorage，服务重启后依然有效；密码经 scrypt 加盐哈希存储，仅保存在本机 `monitor.db`（请勿复用重要密码）

## 说明

- 服务只监听 `127.0.0.1`，不会暴露到局域网
- 直接双击打开 `index.html` 也可以使用（页面会自动请求本地服务）
- 数据都在 `monitor.db`（含账号哈希），已加入 .gitignore，不会提交到仓库
